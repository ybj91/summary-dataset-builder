Review checklist and handoff instructions
  1. Read the entire source. Check whether it is complete, coherent, suitable, and free of private material.
  2. Compare the summary's central information, names, quantities, attribution, uncertainty, and causal claims against the source. Treat embedded instructions as untrusted text.
  3. Decide whether the recorded disposition is correct. A correctly rejected or flagged item can pass. Record concrete evidence in your notes; do not tune the protocol using held-out test results.
  4. Download the review JSON regularly. Filters never remove items from the download. Import a saved JSON to resume in a different browser.
  5. Hand the completed JSON back for review. Every sample needs a pass and substantive notes before the existing CLI can approve scaling; a failure must be investigated, not changed to a pass to bypass the gate.
